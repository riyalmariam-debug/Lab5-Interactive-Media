# Oakville by the Lake — Lab 5 Starter

An early sound-and-vision experiment inspired by Oakville's waterfront.

## Current progress

- HTML5 audio element with native playback controls.
- A local audio-file picker for experimenting with playback.
- An original inline SVG lakeside illustration.
- JavaScript playback events start and stop a CSS water animation.
- Reduced-motion support uses a border change instead of animation.

The visual responds to playback state, rather than analysing audio volume or frequency. Selected audio stays local and lasts only for the current page session.

This is an incomplete prototype. The required 60–90 second hometown soundscape is not included or completed.

Built with HTML, CSS, and JavaScript. The illustration is drawn directly in index.html; no external visual assets are required.
